# Дневник времени

Приложение для Android: учёт того, куда уходит время (как учёт бюджета, только вместо денег минуты).

## Как получить APK

1. Открой вкладку **Actions** этого репозитория.
2. Выбери последний запуск **Build APK** (если запусков нет, нажми **Run workflow**).
3. Дождись зелёной галочки (3–6 минут).
4. Готовый файл `TimeDiary.apk` лежит:
   - в разделе **Releases** справа на главной странице репозитория (проще всего, можно скачать прямо с телефона);
   - или внизу страницы запуска, в блоке **Artifacts**.
5. Открой APK на телефоне. Android попросит разрешить установку из этого источника: разреши.

Новые версии ставятся поверх старых, данные не пропадают (ключ подписи зафиксирован в репозитории).

## Устройство

- `app/src/main/assets/www/` — интерфейс и вся логика (HTML/CSS/JS).
- `app/src/main/java/app/timediary/` — Android-оболочка: таймер в шторке уведомлений (пауза/завершить), напоминания.
- `.github/workflows/build.yml` — автоматическая сборка APK.
